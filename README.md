# 주민 신고 앱 프로토타입 웹 버전
이 프로젝트는 군 복무를 할 때 사단 훈련을 대비하여 훈련의 개선할 점 및 보완할 점을 고안하다가 '군에서 자체적으로 주민 신고 앱을 만들어서 사용하면 훈련뿐만이 아니라 평상시에도 주민 신고에 더 효율적으로 대응할 수 있지 않을까' 하는 의견에서 시작된 프로젝트입니다. 그리하여 간부 1명과 자원한 병사 3명이 팀을 이루어 사단 훈련 전까지 주민 신고 앱의 초안을 제작하여 사단장님에게 프레젠테이션하는 것을 목표로 하는 프로젝트였습니다.
해당 프로젝트는 주민 신고 앱 프로토타입 프로젝트들 중 제가 맡은 웹 버전 프로젝트만 포함되어 있습니다.

## 기능
- 관리자 코드를 이용한 로그인 기능
- 공지 사항 작성 및 확인 기능 (현재는 연결된 데이터 베이스가 없어 작성된 공지 사항이 영구히 저장되지 않습니다.)
- 신고 사항 분류 및 확인 (현재는 연결된 데이터 베이스가 없어 신고 사항이 존재하지 않습니다.)
- 수배 사항 등록, 확인, 제거 (현재는 연결된 데이터 베이스가 없어 작성된 수배 사항이 영구히 저장되지 않습니다.)
